## Code Lexicons (API Name Lists)

`src/shared/code-lexicon/*.json` lists official identifier names (globals,
types, members, module names, keyword-argument names) so that code renaming
keeps library names readable. The lists contain names only — no
documentation, signatures or code — and are generated by
`scripts/build-code-lexicon.js` from machine-readable API descriptions; no
list is written by hand. Remote sources are pinned by version and SHA-256 in
`scripts/code-lexicon/sources.js`. None of these packages is bundled: only
the extracted names are.

- `config.json`
- `tokenizer.json`
- `tokenizer_config.json`
- `onnx/model_q4f16.onnx`
- `onnx/model_q4f16.onnx.data`

The `model_q4f16.onnx` and `model_q4f16.onnx.data` files are modified/generated

model files by the repository's conversion scripts using ONNX Runtime

The active conversion manifest in the release preparation workspace records:

- Method: `converted-float-to-fp16-then-q4f16`
- Quantization: 4 bits, block size 32, symmetric weights, `QOperator` format,
  `MatMul` operators
- `model_q4f16.onnx` SHA-256:
  `3e74fb3e23b59302d850f1cbbf12949d3bd77e9ae8890d866ed884f377b9c59c`

Inactive or intermediate model artifacts such as `model_fp16.onnx`,
`model_fp16.onnx.data`, `model_quantized.onnx`, conversion manifests, and local
source caches are excluded from official release ZIPs by the packaging rules.

## Code Identifier Classifier

The **Rename code identifiers** option uses a token classifier that labels
code identifiers as the user's own (`OWN`) or library/framework names (`LIB`):

- Model ID: `koncsik/code-identifier-classifier`
- Provider: Benedek Koncsik
- Source: https://huggingface.co/koncsik/code-identifier-classifier
- Training pipeline: `tools/identifier-classifier`

The package includes prepared runtime files under
`models/identifier-classifier/`:

- `config.json`
- `tokenizer.json`
- `tokenizer_config.json`
- `onnx/model_quantized.onnx`

The model is fine-tuned from `microsoft/unixcoder-base`
(https://huggingface.co/microsoft/unixcoder-base), which is licensed under
Apache-2.0, and exported to int8-quantized ONNX by the repository's training
scripts. It is a modified/generated Redacto release artifact, not an upstream
file.
